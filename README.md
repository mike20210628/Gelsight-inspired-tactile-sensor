# GelSight-inspired-tactile-sensor
A low-cost vision-based tactile sensor inspired by MIT GelSight.


## Project Goal
The goal of this project is to design and experimentally evaluate a low-cost tactile sensing system using a soft elastomer, controlled illumination, and camera-based deformation analysis.
